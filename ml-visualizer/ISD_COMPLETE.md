**Answer**: "Detecting data leakage automatically is challenging. I implemented multiple strategies:
1. **Perfect correlation detection** - Find features with >0.95 correlation to target
2. **Duplicate column detection** - Identify identical features
3. **Naming heuristics** - Flag suspicious column names like 'target_prediction'

The system combines these into a risk assessment and provides specific warnings. This prevents the common mistake of training on leaked features, which causes unrealistic performance."
